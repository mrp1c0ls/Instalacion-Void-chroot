Guía técnica

Instalar Void Linux mediante chroot

Instalación mínima de Void Linux para x86_64 con glibc, compatible con BIOS heredado y UEFI, usando ext4, GRUB y runit.

Arquitecturax86_64
Biblioteca Cglibc
FirmwareBIOS o UEFI
ArranqueGRUB
Advertencia: esta guía elimina el contenido del disco seleccionado. En los ejemplos se utiliza /dev/sda. Verifica el nombre de tu disco con lsblk y sustituye también los nombres de sus particiones cuando corresponda.

Selecciona el tipo de firmware
La página mostrará únicamente los comandos correspondientes. La ISO debe arrancarse en el mismo modo que se utilizará para instalar el sistema.

1

Comprobar la conexión

Desde la ISO Live de Void, verifica el acceso al repositorio:

ping -c 3 repo-default.voidlinux.org

Si Ethernet no obtuvo una dirección automáticamente:

sudo dhcpcd
2

3

Formatear la partición

BIOS 
sudo mkfs.ext4 -L void-root /dev/sda1
UEFI 
sudo mkfs.vfat -F32 -n VOID_EFI /dev/sda1
sudo mkfs.ext4 -L void-root /dev/sda2
4

Montar el sistema de archivos

BIOS 
sudo mount /dev/sda1 /mnt
findmnt /mnt
UEFI 
sudo mount /dev/sda2 /mnt
sudo mkdir -p /mnt/boot/efi
sudo mount /dev/sda1 /mnt/boot/efi
findmnt /mnt /mnt/boot/efi
5

Instalar el sistema base

Copia las claves de los repositorios e instala el sistema:

BIOS 
sudo mkdir -p /mnt/var/db/xbps/keys
sudo cp /var/db/xbps/keys/* /mnt/var/db/xbps/keys/

sudo XBPS_ARCH=x86_64 xbps-install \
  -S \
  -r /mnt \
  -R https://repo-default.voidlinux.org/current \
  base-system grub sudo nano
UEFI 
sudo mkdir -p /mnt/var/db/xbps/keys
sudo cp /var/db/xbps/keys/* /mnt/var/db/xbps/keys/

sudo XBPS_ARCH=x86_64 xbps-install \
  -S \
  -r /mnt \
  -R https://repo-default.voidlinux.org/current \
  base-system grub-x86_64-efi sudo nano

-r /mnt instala los paquetes tomando /mnt como la raíz del nuevo sistema.

6

Entrar al chroot

La ISO oficial incluye xchroot, que prepara los montajes necesarios:

sudo xchroot /mnt

Si no está disponible, utiliza el método manual:

sudo mount -t proc /proc /mnt/proc
sudo mount --rbind /sys /mnt/sys
sudo mount --make-rslave /mnt/sys
sudo mount --rbind /dev /mnt/dev
sudo mount --make-rslave /mnt/dev
sudo mount --rbind /run /mnt/run
sudo mount --make-rslave /mnt/run
sudo cp -L /etc/resolv.conf /mnt/etc/resolv.conf
sudo chroot /mnt /bin/bash
7

Configurar el sistema

Todos los comandos de esta sección se ejecutan dentro del chroot.

chown root:root /
chmod 755 /

echo "voidlinux" > /etc/hostname

cat > /etc/hosts <<'EOF'
127.0.0.1 localhost
127.0.1.1 voidlinux
::1       localhost ip6-localhost ip6-loopback
EOF

Zona horaria

Sustituye Region/Ciudad por una entrada existente en /usr/share/zoneinfo.

ln -sf /usr/share/zoneinfo/Region/Ciudad /etc/localtime

Idioma

echo 'es_MX.UTF-8 UTF-8' >> /etc/default/libc-locales
echo 'en_US.UTF-8 UTF-8' >> /etc/default/libc-locales
echo 'LANG=es_MX.UTF-8' > /etc/locale.conf
xbps-reconfigure -f glibc-locales

Teclado de consola

echo 'KEYMAP=latam' >> /etc/rc.conf

Tabla de montajes

BIOS 
echo 'LABEL=void-root / ext4 defaults,noatime 0 1' > /etc/fstab
UEFI 
cat > /etc/fstab <<'EOF'
LABEL=void-root /         ext4 defaults,noatime 0 1
LABEL=VOID_EFI  /boot/efi vfat defaults          0 2
EOF

Contraseña de administración

passwd
8

Crear un usuario normal

Sustituye newuser por el nombre de cuenta que quieras utilizar:

useradd -m -G wheel,audio,video,input,storage -s /bin/bash newuser
passwd newuser
EDITOR=nano visudo

Dentro de visudo, habilita:

%wheel ALL=(ALL:ALL) ALL
9

Activar la red con runit

ln -s /etc/sv/dhcpcd /var/service/

En Void, un servicio se habilita creando un enlace desde /etc/sv/ hacia /var/service/.

10

Instalar GRUB

BIOS 
grub-install --target=i386-pc /dev/sda
grub-mkconfig -o /boot/grub/grub.cfg
xbps-reconfigure -fa
grub-mkconfig -o /boot/grub/grub.cfg

GRUB llama i386-pc a su plataforma para BIOS, incluso cuando Void Linux es x86_64. Se instala en el disco /dev/sda, no en la partición /dev/sda1.

UEFI 
grub-install \
  --target=x86_64-efi \
  --efi-directory=/boot/efi \
  --bootloader-id=Void

grub-mkconfig -o /boot/grub/grub.cfg
xbps-reconfigure -fa
grub-mkconfig -o /boot/grub/grub.cfg

Si las variables EFI no están disponibles, monta efivarfs o agrega --no-nvram. Para medios removibles o firmware problemático puede utilizarse --removable.

11

Salir, desmontar y reiniciar

exit
sudo umount -R /mnt
sync
sudo reboot

Retira la memoria USB o ISO cuando el equipo comience a reiniciar.

12

Actualizar tras el primer arranque

sudo xbps-install -Syu

Si XBPS se actualiza a sí mismo, ejecuta el comando nuevamente.
